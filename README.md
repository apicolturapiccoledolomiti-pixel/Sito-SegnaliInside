# Sito SegnaliInside

Landing page statica in HTML/CSS per GainLab by QuantiaSystems.

## Struttura

- `index.html`: pagina principale pronta per GitHub Pages.
- `Qwen_html_20260609_fz03tynkl.html`: versione sorgente GainLab.
- `Qwen_html_20260609_xltv5f8to.html`: variante Accademia Successo Digitale.

## Anteprima locale

Apri `index.html` nel browser, oppure avvia un piccolo server locale:

```powershell
python -m http.server 5174
```

Poi visita `http://127.0.0.1:5174`.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository su GitHub.
2. Collega questo progetto al repository remoto.
3. Fai push del branch principale.
4. In GitHub vai su `Settings > Pages` e scegli la pubblicazione dalla root del branch principale.
